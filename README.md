# Giovan Michael — Personal Site

Author and educator site, comic-panel desert design. Plain HTML/CSS/JS, no build step.

**Signature element:** the whole page is structured like comic panels, thick ink
borders, offset drop shadows, hand-lettered caption boxes, opening with an inked
desert horizon illustration (mesas, a Joshua tree, and a rising sun) that nods to
his work in graphic narratives and memoir comics.

**Sections:** Hero (photo, intro, resume download) → About → Craft (skills) →
Publications → Praise (testimonials, placeholder) → Contact.

## Deploy to GitHub Pages

1. Create a repo named exactly `giomichael.github.io` under his GitHub account.
2. Upload `index.html`, `css/style.css`, `js/main.js`, and everything in `assets/`
   (`assets/gioheadshot.png`, `assets/gioresume.pdf`), preserving folder structure.
3. **Settings → Pages → Source: Deploy from a branch → main → / (root) → Save.**
4. Live in 1–2 minutes at `https://giomichael.github.io`.
